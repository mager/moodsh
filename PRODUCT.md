# Product

## Register

brand

## Users

Developers who enjoy personalizing their terminal but want less configuration and fewer moving pieces than a shell framework. The existing README supports first-time users installing a binary without Rust, alongside developers editing Markdown themes.

## Product Purpose

Mood Shell is a small Rust toolkit for prompt colors and layouts across macOS, Linux, and Windows. The website introduces the toolkit, helps visitors install it, and provides the basic theme-sharing community requested by its creator. Successful visits end in an installed prompt or a downloaded, personalized theme.

## Brand Personality

Personal, playful, direct. The creator values simplicity, modern presentation, easy personalization, and the pleasure of a terminal that feels like theirs. Use concrete examples and show the actual palettes.

## Anti-references

Avoid the complexity of a full plugin framework, which the README explicitly places outside the product's scope. Avoid presenting terminal backgrounds, animation, or inline history suggestions as shipped Mood Shell features. Avoid invented community members, download counts, and endorsements.

## Design Principles

- Let people try the colors before installing.
- Keep Markdown themes readable and portable.
- Make the download path usable without Cargo.
- Distinguish terminal settings from prompt settings.
- Start with the smallest honest community and preserve author credit.

## Accessibility & Inclusion

The CLI documents ASCII symbols, no required special font, and NO_COLOR support. Carry that inclusive intent to the web: real text, labeled controls, keyboard navigation, visible focus, adequate contrast, and reduced-motion support. No additional user-specific accessibility requirements have been requested.
